TITLE: intro: how this manual is organised
GROUP: Introduction
USES: every page after this one
SUMMARY: One page per header, function family or system file, laid out like
  a man page: NAME, SYNOPSIS, DESCRIPTION, STANDARDS, NOTES, APPLICATION
  USAGE, then an EXAMPLE that is compiled and run on this machine, and SEE
  ALSO. The output shown is what this machine printed, not a copy.
NOTES:
  - Standard C (ISO C) is the same everywhere a C compiler exists. POSIX is the
    Unix standard: Linux, macOS and the BSDs have it, Windows does not. Linux-
    specific means this kernel and glibc only: sysinfo, the /proc and /sys
    files, CLOCK_BOOTTIME.
  - The examples compile with  cc -std=gnu11 -Wall -Wextra page.c . With a
    strict  -std=c11  the POSIX names are hidden unless you put
    #define _POSIX_C_SOURCE 200809L before the first include.
  - libc is linked automatically. A page whose SYNOPSIS says "Link with" needs
    those flags after the source file (math.h needs -lm).
  - Where a call can fail, the page shows how: the return value to test and
    the errno to read (see errno.h).
  - Type a word at the page list to search every page, including the code.
SEE: man 7 standards, man 7 feature_test_macros, man 7 libc

  ----------------  -------------------------------------------

  math.h            ISO C, link with -lm
  time.h            ISO C (clock_gettime, strptime: POSIX)
  errno.h           ISO C (most E* names: POSIX)
  stdint.h          ISO C99
  ctype.h           ISO C
  stdbool.h         ISO C99 (keywords in C23)
  limits.h          ISO C (PATH_MAX, HOST_NAME_MAX: POSIX)
  locale.h          ISO C (langinfo.h: POSIX)
  wchar.h           ISO C (wcwidth: POSIX, XSI option)
  unistd.h          POSIX
  sys/types.h       POSIX
  sys/stat.h        POSIX
  fcntl.h           POSIX
  dirent.h          POSIX
  pwd.h             POSIX

  sys/statvfs.h     POSIX

  termios.h         POSIX

  ifaddrs.h         BSD, provided by glibc
  sys/sysinfo.h     Linux only

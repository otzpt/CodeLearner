EXERCISE 5

One id against ten classes. Which wins?

Answer

The id. Specificity compares column by column.

What is the specificity of :where(#a, .b)?

Answer

Zero. That is the whole point of :where().

An unlayered p against a layered #x. Which wins?

Answer

The unlayered p. Layer order comes before specificity.

Challenge

Build a light and dark theme with custom properties, using no script.

Input: tick a checkbox on your page.

The result must be:

  • Colours are defined once, as custom properties.
  • Ticking the box switches the whole page to dark colours.
  • Unticking it switches back.
Example solution (one way of getting there) 
<style>
  body { --bg: white; --text: black; background: var(--bg); color: var(--text); }
  body:has(#dark:checked) { --bg: #222; --text: #eee; }
</style>
<label><input type="checkbox" id="dark"> Dark</label>
<p>Some text.</p>

SUMMARY

  • Specificity is compared column by column, then source order decides.
  • An invalid var() falls back to inherited or initial, not to the previous rule.
  • :is() takes its argument's weight. :where() weighs nothing.
  • Unlayered styles beat layered ones.
  • :has() selects by contents, and rules can be nested with &.

PART 2: sharing out the space

flex: 1 means take an equal share of what is left. gap puts space between items without any margin on the outer edges. margin-left: auto on one item pushes it away from the others:

PART 3: the item that refuses to shrink

A flex item will not shrink below the size of its content, unless you say so. One long word is enough to break a layout. The red outline is the container:

The default is min-width: auto, which for a flex item means no smaller than its content. This is the usual cause of a page that scrolls sideways for no visible reason.

Challenge

Build a navigation bar using Flexbox.

Input: nothing to type. Make the window narrower and wider to test it.

The result must be:

  • A logo on the left, two links after it, and a sign-in link at the far right.
  • There is space between the items but none before the first.
  • The logo is vertically centred against the links.
Example solution (one way of getting there) 
<style>
  nav { display: flex; align-items: center; gap: 16px; }
  .logo { font-size: 2rem; }
  .signin { margin-left: auto; }
</style>
<nav>
  <span class="logo">Logo</span>
  <a href="#a">Home</a>
  <a href="#b">About</a>
  <a class="signin" href="#c">Sign in</a>
</nav>

SUMMARY

  • justify-content follows the main axis, and flex-direction decides which axis that is.
  • flex: 1 shares the remaining space.
  • Items refuse to shrink below their content until you set min-width: 0.
  • flex-wrap: wrap lets items move to a new line.

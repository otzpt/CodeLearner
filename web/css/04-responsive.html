EXERCISE 4

1.5em inside 1.5em on a 16px root. What font size results?

Answer

36px 16 times 1.5 times 1.5.

Does a media query add specificity?

Answer

No. A later plain rule still wins.

Which kind of query lets a component react to the space it was given?

Answer

A container query. @container, with container-type on the parent.

Challenge

Write a page with a main area and a sidebar.

Input: nothing to type. Resize the window across 600 pixels.

The result must be:

  • Below 600 pixels the sidebar is under the main area, full width.
  • From 600 pixels up they are side by side, and the sidebar is 200 pixels wide.
  • The heading size changes smoothly with the window, between 24 and 48 pixels.
Example solution (one way of getting there) 
<style>
  h1 { font-size: clamp(24px, 6vw, 48px); }
  .page { display: block; }
  @media (min-width: 600px) {
    .page { display: grid; grid-template-columns: minmax(0, 1fr) 200px; }
  }
</style>
<h1>Title</h1>
<div class="page"><main>Main</main><aside>Sidebar</aside></div>

SUMMARY

  • em multiplies when nested. rem does not.
  • Base rules first, media queries after them.
  • clamp() gives a value limits on both sides.
  • @container responds to the available space, not the window.

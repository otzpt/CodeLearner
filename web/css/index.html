CSS course

This course is written in HTML and CSS. There is no JavaScript anywhere in it. Every effect you see is the CSS shown right above it, running in a frame, so you can right-click and Inspect it.

Each module explains something, shows it running, then asks a few questions and sets a challenge to write in your own file. It assumes you can write a basic HTML page, which is the first module of the HTML course.

PART 2: responsive with no media query

repeat(auto-fit, minmax(120px, 1fr)) means as many columns as fit, none under 120 pixels. The same CSS is shown at two widths:

With two items and room for four columns, auto-fit stretches the two across the whole width. Change it to auto-fill and the empty columns keep their space, so the items stay narrow.

EXERCISE 3

grid-template-columns: 1fr 1fr 2fr on a 400px grid with no gap. How wide is the last column?

Answer

200px It gets two of the four shares.

In grid-column: 1 / -1, what does -1 mean?

Answer

The last line. So the item spans every column.

With few items, which keeps empty columns, auto-fit or auto-fill?

Answer

auto-fill auto-fit collapses them.

Challenge

Build a photo gallery of six boxes with Grid, using no media query.

Input: nothing to type. Resize the window to test it.

The result must be:

  • Boxes are never narrower than 150 pixels.
  • The number of columns changes as the window is resized.
  • The first box spans the whole first row.
Example solution (one way of getting there) 
<style>
  .gallery {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(150px, 1fr));
    gap: 8px;
  }
  .gallery div { height: 100px; background: khaki; }
  .gallery .wide { grid-column: 1 / -1; }
</style>
<div class="gallery">
  <div class="wide"></div><div></div><div></div><div></div><div></div><div></div>
</div>

SUMMARY

  • fr is a share of the free space.
  • repeat(auto-fit, minmax(...)) adapts with no media query.
  • grid-template-areas draws the layout in text.
  • minmax(0, 1fr) stops content forcing a column wider.

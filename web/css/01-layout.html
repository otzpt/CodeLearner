PART 1: width does not mean what you expect

By default width sets the width of the content only. Padding and border are added on top. The red bar below is 200 pixels long:

Most stylesheets start by making every element behave like the second box: * { box-sizing: border-box; }.

PART 2: vertical margins collapse

The first paragraph has a bottom margin of 40 pixels and the second a top margin of 20. You might expect a gap of 60. The red bar is 40 pixels tall:

Horizontal margins never collapse, and neither do the margins of flex or grid items. That is often why a gap changes when the parent becomes display: flex.

PART 4: absolute is relative to something

An absolutely positioned element is placed against its nearest ancestor that has a position of its own. If there is none, it is placed against the whole page.

Challenge

Make a file with one box that has a 4 pixel border and 16 pixels of padding.

Input: nothing to type.

The result must be:

  • The whole box, border included, is exactly 300 pixels across. Check it in DevTools.
  • A small label sits in its top-right corner, inside the box.
Example solution (one way of getting there) 
<style>
  .card {
    box-sizing: border-box;
    width: 300px;
    padding: 16px;
    border: 4px solid steelblue;
    position: relative;
  }
  .label { position: absolute; top: 0; right: 0; }
</style>
<div class="card">Content<span class="label">new</span></div>

SUMMARY

  • box-sizing: border-box makes width mean what you expect.
  • Vertical margins collapse. Horizontal ones and flex items do not.
  • Inline elements ignore width.
  • position: absolute needs a positioned ancestor, and z-index needs a position.

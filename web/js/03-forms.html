PART 3: submit, without leaving the page

A form navigates when it is submitted. event.preventDefault() stops that. FormData then reads what would have been sent, with the same rules: no name means not included, and an unticked box is simply absent.

EXERCISE 3

valueAsNumber gives a number.

value is on either way.

Called on the submit event.

Challenge

Write a form with two number fields and a button. On submit, show their sum in the page, without the page reloading.

Input: the numbers 5 and 3, then press the button.

The result must be:

  • The page shows 8, not 53.
  • The page does not reload.
Example solution (one way of getting there) 
<form id="sum">
  <input name="a" type="number" required>
  <input name="b" type="number" required>
  <button>Add</button>
</form>
<p id="result"></p>
<script>
  document.querySelector("#sum").addEventListener("submit", (event) => {
    event.preventDefault();
    const { a, b } = event.target.elements;
    document.querySelector("#result").textContent = a.valueAsNumber + b.valueAsNumber;
  });
</script>

SUMMARY

  • .value is always a string.
  • .checked is the state of a checkbox.
  • preventDefault() keeps you on the page.
  • FormData follows the same rules as a real submission.

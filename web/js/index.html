Web JavaScript course

JavaScript where it was born: in a page. The course in this project's JavaScript folder runs in a terminal under Node and has no page to work with. This one covers what only a browser has, and each code box runs when the page loads.

It assumes you know variables, functions, arrays and if, which are the first modules of that terminal course. Each module ends with questions and a challenge to write in your own file. The helpers it uses are in course.js, which you can read.

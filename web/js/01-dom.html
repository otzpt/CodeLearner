EXERCISE 1

The crash comes when you use it.

It never parses HTML.

It only works on external scripts.

Challenge

Write a page with an empty ul whose list items are created by JavaScript from an array.

Input: the array ["milk", "eggs", "bread"] in your script.

The result must be:

  • The page lists milk, eggs and bread, one per line.
  • The script does not use innerHTML.
Example solution (one way of getting there) 
<ul id="shopping"></ul>
<script>
  const list = document.querySelector("#shopping");
  for (const name of ["milk", "eggs", "bread"]) {
    const item = document.createElement("li");
    item.textContent = name;
    list.append(item);
  }
</script>

SUMMARY

  • querySelector returns null for no match, so check before you use it.
  • A script can only see what has already been parsed. Use defer.
  • innerHTML on user input is cross-site scripting.
  • querySelectorAll is a snapshot.

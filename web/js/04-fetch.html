EXERCISE 4

Only when no response arrived.

response.ok.

The second attempt throws, as part 1 printed.

Challenge

Write a page with a button that fetches https://jsonplaceholder.typicode.com/posts/1 and shows its title.

Input: click the button.

The result must be:

  • The title of the post appears in the page.
  • With the network off, a readable message appears instead of nothing.
  • A failed HTTP status is treated as a failure.
Example solution (one way of getting there) 
<button id="load">Load</button>
<p id="out"></p>
<script>
  const out = document.querySelector("#out");
  document.querySelector("#load").addEventListener("click", async () => {
    try {
      const response = await fetch("https://jsonplaceholder.typicode.com/posts/1");
      if (!response.ok) {
        throw new Error("HTTP " + response.status);
      }
      const post = await response.json();
      out.textContent = post.title;
    } catch (error) {
      out.textContent = "Could not load it: " + error.message;
    }
  });
</script>

SUMMARY

  • fetch takes two awaits: the response, then the body.
  • A 404 does not reject. Check response.ok.
  • A body can be read once.
  • AbortSignal.timeout() gives a request a limit.
  • Pages opened from file:// are restricted.

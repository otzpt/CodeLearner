Challenge

Write a page with a counter: a number and two buttons, plus and minus. Use one listener, on the element that contains both buttons.

Input: click plus three times, then minus once.

The result must be:

  • The number starts at 0.
  • After those clicks it shows 2.
  • There is exactly one addEventListener call.
Example solution (one way of getting there) 
<div id="counter">
  <button data-step="1">+</button>
  <span id="value">0</span>
  <button data-step="-1">-</button>
</div>
<script>
  let value = 0;
  document.querySelector("#counter").addEventListener("click", (event) => {
    if (event.target.matches("button")) {
      value += Number(event.target.dataset.step);
      document.querySelector("#value").textContent = value;
    }
  });
</script>

SUMMARY

  • Pass the function. fn() calls it at once.
  • Events bubble. target is the origin and currentTarget is the listener's element.
  • Delegation covers elements that do not exist yet.
  • Removing a listener needs the same function object.
  • innerHTML += destroys the listeners inside.

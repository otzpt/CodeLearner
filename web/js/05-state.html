EXERCISE 5

Everything becomes a string.

JSON.parse restores it.

Then draw from it.

Challenge

Write the counter from module 2 again, so that it survives a page reload.

Input: click plus twice, then reload the page.

The result must be:

  • After the reload the counter still shows 2.
  • The value is held in a variable and drawn from it.
  • A first visit, with nothing saved, shows 0.
Example solution (one way of getting there) 
<div id="counter">
  <button data-step="1">+</button>
  <span id="value"></span>
  <button data-step="-1">-</button>
</div>
<script>
  let value = Number(localStorage.getItem("count") ?? 0);

  function draw() {
    document.querySelector("#value").textContent = value;
    localStorage.setItem("count", value);
  }

  document.querySelector("#counter").addEventListener("click", (event) => {
    if (event.target.matches("button")) {
      value += Number(event.target.dataset.step);
      draw();
    }
  });

  draw();
</script>

SUMMARY

  • localStorage stores strings, so use JSON for anything else.
  • Keep state in variables and draw the page from it.
  • Build user content with createElement and textContent.

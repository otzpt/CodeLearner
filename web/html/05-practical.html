Module 5: Practical pages

PART 1: tables are for data

A table has a caption, and header cells that say what they head. Layout belongs to CSS.

PART 2: images should reserve their space

Until an image loads, the browser does not know its size unless you say so. Text below it then jumps down when the image arrives. These two images never load, so the difference stays visible:

Both images use an empty alt so the demo shows only the reservation. If an image with alt text fails for good, the browser draws the text instead and ignores the two attributes.

Add loading="lazy" to images far down a long page so that they are only fetched when they are close to being seen.

EXERCISE 5

Which two attributes stop a page jumping when an image loads?

Answer

width and height The browser reserves the space in advance.

Which element gives a collapsible section with no script?

Answer

details Its summary child is the part you click.

Should a table be used to put two columns of text side by side?

Answer

No. Tables are for data. Layout is CSS's job.

Challenge

Write recipe.html, a recipe page using only HTML.

Input: nothing to type, except Tab and Enter to test it.

The result must be:

  • One h1, and h2 headings for ingredients and method.
  • An ingredients list, and numbered steps.
  • A table of cooking times with a caption and th cells.
  • An image with alt, width and height.
  • A details section holding a tip, which opens with the keyboard.
Example solution (one way of getting there) 
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Pancakes</title>
</head>
<body>
  <main>
    <h1>Pancakes</h1>
    <img src="pancakes.jpg" alt="A stack of pancakes" width="400" height="200">
    <h2>Ingredients</h2>
    <ul><li>Flour</li><li>Milk</li><li>One egg</li></ul>
    <h2>Method</h2>
    <ol><li>Mix.</li><li>Fry.</li></ol>
    <table>
      <caption>Cooking times</caption>
      <tr><th scope="col">Size</th><th scope="col">Minutes per side</th></tr>
      <tr><td>Small</td><td>1</td></tr>
    </table>
    <details><summary>A tip</summary><p>Rest the batter.</p></details>
  </main>
</body>
</html>

SUMMARY

  • Tables are for data, with a caption and th scope.
  • width and height reserve an image's space.
  • details and popover work with no script at all.
  • A correct page is mostly choosing the right elements.

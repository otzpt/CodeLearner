HTML course

This course is written in HTML, the language it teaches: there is no JavaScript anywhere in it, and the one stylesheet only makes the text readable. Everything you see working, you can right-click and Inspect.

Each module explains something, shows it running in a frame, then asks a few questions and sets a challenge. The challenges are for you to write in your own file and open in this browser. A text editor is all you need.

PART 1: a label is more than text next to a box

The for attribute has to equal the input's id. A screen reader also reads the label when the field gets focus. Without one, the field is announced with no name.

PART 2: a field with no name is not sent

That shows two traps at once. The field with no name vanished without any error. And method="get" put the password in the URL, where it stays in the browser history. Anything sensitive uses method="post", and that still needs HTTPS.

PART 4: a button in a form submits it

A <button> with no type inside a form is type="submit". Write type="button" on every button that is not meant to send the form.

EXERCISE 2

Which attribute on an input decides whether its value is sent at all?

Answer

name No name, no entry in what is sent.

Is required enough to guarantee a server receives a value?

Answer

No. It runs in the browser, and novalidate or DevTools removes it.

What type does a <button> inside a form have when none is written?

Answer

submit So it sends the form when pressed.

Challenge

Write signup.html with a sign-up form. Use action="" and method="get" so the result shows in your own address bar.

Input: type an email and an age into your form, then submit.

The result must be:

  • Clicking the words Email or Age puts the cursor in that field.
  • Submitting with the email empty is refused by the browser.
  • An age of 200 is refused. The limit is 120.
  • After a valid submit the address bar contains email= and age=.
Example solution (one way of getting there) 
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Sign up</title>
</head>
<body>
  <form action="" method="get">
    <p><label for="email">Email</label>
       <input id="email" name="email" type="email" required></p>
    <p><label for="age">Age</label>
       <input id="age" name="age" type="number" min="0" max="120"></p>
    <button>Sign up</button>
  </form>
</body>
</html>

SUMMARY

  • <label for> makes the text clickable and names the field for screen readers.
  • A field with no name is not sent, and nothing warns you.
  • method="get" puts values in the URL. Never use it for passwords.
  • Browser validation is a convenience. The server decides.
  • A button in a form submits it unless it says type="button".

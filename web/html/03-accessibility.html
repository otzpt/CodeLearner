Module 3: Accessibility

PART 1: put the mouse down and press Tab

Click inside this frame, then press Tab a few times and watch where the focus goes:

A <button> gets keyboard focus, Enter and Space for free. A styled <div> gets none of them. Someone who cannot use a mouse cannot reach it at all.

PART 2: ARIA changes the label, not the behaviour

role="button" tells a screen reader that this is a button. It adds no keyboard support. Press Tab again:

The first rule of ARIA is to prefer the native element. A <button> needs no role, no tabindex and no key handling, and it cannot be half finished.

PART 3: text alternatives

These images do not exist, which is also what happens on a slow connection:

  • alt says what the image communicates, not the word photo.
  • A purely decorative image gets alt="", so a screen reader skips it.
  • With no alt attribute at all, a screen reader may read the file name out loud.

PART 4: links and colour

Screen reader users often list every link on a page, so link text has to make sense on its own. A list of click here says nothing.

Do not carry meaning in colour alone. A field marked only by a red border says nothing to someone who cannot see the red. Say it in words as well.

EXERCISE 3

A <div role="button"> can it be reached with the Tab key?

Answer

No. A role changes what is announced. It adds no behaviour.

What should alt be on a decorative image?

Answer

Empty. alt="", so the image is skipped.

Which element do you use for something that performs an action on the page?

Answer

button Keyboard support comes with it.

Challenge

Write card.html with one image, a heading, and an action the user can trigger.

Input: only the Tab key, no mouse.

The result must be:

  • With the image file missing, its description is visible.
  • Tab reaches the action, and Enter activates it.
  • The link in the page does not say click here.
Example solution (one way of getting there) 
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Card</title>
</head>
<body>
  <main>
    <h1>Lisbon trip</h1>
    <img src="tram.jpg" alt="A yellow tram climbing a narrow street">
    <p><a href="trip.html">Read the Lisbon trip notes</a></p>
    <button type="button">Save for later</button>
  </main>
</body>
</html>

SUMMARY

  • Test with the Tab key. It takes ten seconds.
  • Native elements come with behaviour. Styled divs do not.
  • ARIA changes what is announced and nothing else.
  • alt describes what the image communicates, and is empty on decoration.
  • Link text and meaning must survive without sight of the page around them.

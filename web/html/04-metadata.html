Module 4: Metadata

PART 1: the charset line

A file is bytes. <meta charset> says how to turn them into letters. These two pages hold exactly the same bytes, written as UTF-8. Only the declaration differs:

<!doctype html>
<html lang="pt-PT">
<head>
<meta charset="iso-8859-1">
<title>Charset demo</title>
</head>
<body>
<p>José comeu pão em São João: 5 €</p>
</body>
</html>

The browser only looks for this declaration in the first 1024 bytes, so it goes first in the <head>. Save your files as UTF-8 and declare UTF-8.

PART 2: the viewport line

Phones lay a page out as if the screen were about 980 pixels wide and then shrink it, unless the page says otherwise. Open each page below, then turn on device mode in DevTools (Ctrl+Shift+M in Chrome):

<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Viewport demo</title>
</head>
<body>
<h1>How wide is this line of text on a phone?</h1>
<p>Open this in your browser's device mode and compare the two versions.</p>
</body>
</html>
  • With the viewport line: text at normal reading size.
  • Without it: the same text, tiny.

PART 3: what is read by other programs

Some tags have no effect you can see in the page:

<meta name="description" content="One sentence about this page.">
<link rel="canonical" href="https://example.com/article">
<meta property="og:title" content="Title shown in a link preview">
<meta property="og:image" content="https://example.com/preview.png">

Search engines may use the description as the snippet in their results, and messaging apps read the og: tags to draw a link preview. This course cannot run a search engine, so that sentence is stated and not demonstrated. What you can see for yourself is the <title>: it is the text in the browser tab and the default name of a bookmark.

EXERCISE 4

How far into the file does the charset declaration have to be?

Answer

Within the first 1024 bytes. So it goes first in the head.

Which tag stops phones laying a page out at a desktop width?

Answer

The viewport meta tag. width=device-width is the part that matters.

What does <title> set that you can see without any other software?

Answer

The text in the browser tab. It is also the default bookmark name.

Challenge

Add a complete head to the about.html from module 1.

Input: nothing to type.

The result must be:

  • The name José written in the page displays correctly.
  • In device mode the text is at normal reading size.
  • The browser tab shows your title.
  • The source has a description of one sentence.
Example solution (one way of getting there) 
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>About José</title>
  <meta name="description" content="José's page about learning HTML.">
</head>

SUMMARY

  • <meta charset="utf-8"> first in the head, and files saved as UTF-8.
  • No viewport tag means a shrunken page on a phone.
  • description and og: tags are for other programs, not for your page.
  • <base> rewrites every relative URL, including #anchors.
